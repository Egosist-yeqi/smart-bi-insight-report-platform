# 指标口径与数据范围说明

## 1. 为什么需要这一页

分析结果只有在“数据覆盖到哪里、指标按什么公式计算”明确时才值得解读。系统在仪表盘中增加“指标口径与数据范围”，用于把当前数据集的范围和已登记指标直接展示给业务用户。

## 2. 在系统中如何查看

1. 打开左侧“仪表盘”。
2. 在筛选器下方查看“指标口径与数据范围”。
3. 先确认记录数、数据起止日期和有效月份，再解释趋势、异常或预测。
4. 展开“查看 N 项已启用指标口径”，核对每个指标的名称、公式和业务说明。

场景切换和确认导入自有 CSV 后，该区域会自动读取新的数据集并刷新范围信息。

## 3. 当前展示字段

| 字段 | 含义 | 使用建议 |
| --- | --- | --- |
| 记录数 | 当前 `sales_order` 明细行数 | 数据量过少时，排行和异常仅作试用验证。 |
| 数据起止 | 最早和最晚业务日期 | 结论不应外推到此范围外。 |
| 有效月份 | 当前数据中实际出现的不同年月数 | 少于 3 个月时，趋势与预测参考价值有限。 |
| 可用维度 | 组织、分类、对象类型的不同值个数 | 维度只有一个时，对比分析能力受限。 |
| 指标公式 | 来自 `metric_definition` 的受控计算公式 | 查询、仪表盘和报告应按已登记口径解释。 |

## 4. 当前指标口径

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 销售额/经营金额 | `SUM(amount)` | 场景中显示为 GMV、服务收入、业务收入、订单产值或订阅收入。 |
| 销售数量 | `SUM(quantity)` | 场景中显示为件数、人次、办理笔数、交付数量或付费席位。 |
| 订单量 | `COUNT(*)` | 当前数据明细记录数量。 |
| 客单价 | `SUM(amount) / COUNT(*)` | 每条业务记录的平均金额。 |
| 毛利 | `SUM(profit)` | 当前收益口径下的总收益；收益率由 `SUM(profit) / SUM(amount)` 实时计算。 |

## 5. 当前边界与下一步

当前 MVP 展示的是已登记口径和数据覆盖范围，不支持在页面中修改公式，也没有指标版本、责任人、审批流或血缘图。这些将作为指标治理的下一阶段：先固化版本与负责人，再将报告、AI 提示和导出文件绑定到相应的指标版本。
