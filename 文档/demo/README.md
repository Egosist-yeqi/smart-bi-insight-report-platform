# 演示素材包

本目录用于答辩、课堂展示和项目交接。所有素材都能直接使用，不包含真实 API Key 或个人数据。

- [全功能演示素材库](全功能演示素材库.md)：12 分钟完整剧本、五行业案例卡、真实业务话术和证据点。
- [业务角色任务卡](业务角色任务卡.md)：经营负责人、分析师、运营负责人、汇报专员、数据管理员和 AI 管理员的操作任务。
- [演示讲稿](演示讲稿.md)：约 6 分钟的讲解顺序和可直接朗读的话术。
- [演示问题清单](演示问题清单.md)：可复制到顶部输入框或“智能查询”页面的问题。
- [演示检查清单](演示检查清单.md)：演示前、演示中和演示后的检查项。
- [功能演示文档](../DEMO_GUIDE.md)：具体说明在哪个页面输入什么。
