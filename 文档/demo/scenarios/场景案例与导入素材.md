# 场景案例与导入素材

## 真实业务化素材设计

场景库中的 5 套数据均为可复现的合成演示数据：每套有 540 条业务明细，覆盖 18 个月、5 个组织/区域、6 个对象/产品、多个类别和对象类型。数值根据行业单价、区域系数和时间波动生成，用于模拟经营分析过程，不代表任何真实企业数据。

| 场景 | 管理者关心的经营问题 | 适合展示的页面 | 推荐收尾行动 |
| --- | --- | --- | --- |
| 电商经营 | 区域 GMV、品类组合、会员/新客、促销影响 | 查询、仪表盘、行动中心 | 核查商品组合与履约节奏，建立 7 天复购跟踪。 |
| 医院运营 | 院区服务收入、科室结构、服务人次、号源和排期 | 场景库、仪表盘、异常归因 | 联动科室核查号源、检查排期和服务结构。 |
| 银行经营 | 分行业务收入、客群分层、业务条线、办理笔数 | 查询、异常、行动中心 | 建立重点客户清单，跟进产品费率和客户经理触达。 |
| 制造业经营 | 工厂产值、产品线、交付数量、项目验收 | 仪表盘、预测、报告 | 核查订单、报价、交付和验收节点。 |
| 互联网公司经营 | 订阅收入、客户分层、付费席位、市场投入 | 查询、情景模拟、报告 | 建立续费和扩容清单，跟踪转化与留存。 |

## CSV 导入样表

[自有数据导入示例_电商.csv](自有数据导入示例_电商.csv) 是一份 36 条的模拟电商月度业务明细，可直接用于“检查数据质量”和“确认导入并替换当前数据”。它刻意包含 6 个月、3 个区域、6 个商品和 4 类用户，使导入后仍可演示趋势、区域、品类、客户类型、毛利和数据版本追溯。

导入步骤：

1. 进入“场景库”，将行业模板选为“电商经营”。
2. 选择 CSV 文件，点击“检查数据质量”。
3. 确认预检的记录数、日期范围、维度数和金额/收益汇总。
4. 点击“确认导入并替换当前数据”。
5. 使用以下问题继续演示：`本月各区域GMV / 交易额排名如何？`、`本月各商品品类GMV / 交易额排名如何？`、`下个月GMV / 交易额可能是多少？`。

## 11 字段对照

| CSV 字段 | 业务含义 | 电商示例 |
| --- | --- | --- |
| `record_id` | 明细唯一编号 | `EC-2026-06-036` |
| `date` | 业务发生日期 | `2026-06-25` |
| `region` | 区域/组织 | `华东` |
| `province` | 城市或省份 | `上海` |
| `item_id` | 对象数字编号 | `1001` |
| `item_name` | 商品或服务名称 | `智能穿戴旗舰款` |
| `category` | 经营分类 | `数码家电` |
| `customer_type` | 客户分层 | `会员用户` |
| `quantity` | 件数、人次、笔数或席位 | `18` |
| `amount` | 金额 | `44982` |
| `profit` | 收益 | `10346` |

不要修改首行字段名。日期使用 `YYYY-MM-DD`，`item_id`、`quantity` 使用整数，`amount`、`profit` 使用非负数字；避免空记录编号、空日期或重复编号。
