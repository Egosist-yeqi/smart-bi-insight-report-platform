# 演示检查清单

## 演示前

- [ ] 双击 `启动智能BI系统.cmd`，浏览器已打开 `http://localhost:8080`。
- [ ] 左下角状态显示数据库正常和本地分析。
- [ ] 准备好 [演示问题清单](演示问题清单.md)。
- [ ] 准备好 [全功能演示素材库](全功能演示素材库.md)；需要导入演示时，确认 [模拟电商 CSV](scenarios/自有数据导入示例_电商.csv) 可访问。
- [ ] 不在屏幕或截图中展示真实 API Key、`.env` 内容和 Docker 密码。

## 演示中

- [ ] 至少完成一次自然语言查询。
- [ ] 至少展示一次仪表盘筛选。
- [ ] 至少生成一次月报并说明 Markdown 导出。
- [ ] 展示异常归因与趋势预测的定位。
- [ ] 至少演示一次“建议草案 -> 执行中 -> 已复盘”的行动闭环。
- [ ] 至少说明一次 CSV 预检不写入数据，以及正式导入后的数据版本追溯。
- [ ] 说明默认本地模式可用，自有 API 是可选能力。

## 演示后

- [ ] 需要关闭服务时双击 `停止智能BI系统.cmd`。
- [ ] 需要清除演示数据时，使用 README 中带确认参数的重置命令；普通停止不会清除数据。
