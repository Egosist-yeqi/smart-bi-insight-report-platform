# 全功能演示素材库

本素材库覆盖当前系统全部用户可见功能，适合 10 至 12 分钟答辩、课堂演示和项目交接。每一步均可在默认本地规则模式下完成；外部 AI 是可选增强，不是演示前提。

## 演示主线

**业务背景：** 某全国性零售企业的管理层发现月度经营表现出现波动，需要快速回答四个问题：发生了什么、为什么发生、接下来怎么办、行动是否有效。

**推荐场景：** 先使用“电商经营”建立主线；时间充足时切换到“医院运营”或“制造业经营”，证明系统不是只服务单一行业。

**演示原则：** 查询页呈现事实，异常页呈现预警线索，预测页呈现趋势假设，行动中心记录人工决策。不要把预测、异常或 AI 文字说成已经证实的因果结论。

## 五行业案例卡

### 电商经营：区域 GMV 波动

- **角色：** 电商运营负责人。
- **问题背景：** 华东促销期结束后，管理层想确认区域、品类和用户结构是否发生变化。
- **建议问题：** `为什么华东GMV / 交易额出现变化？`、`本月各商品品类GMV / 交易额排名如何？`、`针对华东GMV / 交易额表现，下一步优先核查什么？`。
- **行动示例：** 负责人“王晨”，目标指标“华东 GMV 与复购订单”，数据证据“华东区域月度 GMV、会员用户贡献和商品品类排行”。
- **业务边界：** 促销模拟用于测算方向，不可替代实际价格审批和库存验证。

### 医院运营：院区服务收入波动

- **角色：** 运营管理部主任。
- **问题背景：** 东院区门诊与检查服务收入表现变化，需要同时关注服务能力和患者体验。
- **建议问题：** `本月各院区服务收入排名如何？`、`为什么东院区服务收入出现变化？`、`本月服务收入最需要优先关注哪个院区？`。
- **行动示例：** 负责人“李敏”，目标指标“东院区服务人次与服务收入”，数据证据“号源、检查排期、科室服务结构与复诊患者贡献”。
- **业务边界：** 演示数据不包含诊疗决策信息，不可用于医疗诊断或临床判断。

### 银行经营：分行业务收入变化

- **角色：** 分行经营分析经理。
- **问题背景：** 华东分行需要分析业务条线、客户分层和办理笔数对收入的影响。
- **建议问题：** `本月各分行业务收入排名如何？`、`哪个业务条线的毛利偏低，需要核查？`、`针对华东分行业务收入表现，下一步优先核查什么？`。
- **行动示例：** 负责人“周昊”，目标指标“重点客群办理笔数与业务收入”，数据证据“产品费率、客户经理跟进和重点客户交易清单”。
- **业务边界：** 演示数据不涉及客户隐私、授信决策或合规审批。

### 制造业经营：工厂订单产值下滑预警

- **角色：** 制造运营总监。
- **问题背景：** 东部工厂需要确认产品线、报价和交付验收节奏对订单产值的影响。
- **建议问题：** `本月各工厂订单产值排名如何？`、`为什么东部工厂订单产值出现变化？`、`下个月订单产值可能是多少？`。
- **行动示例：** 负责人“陈工”，目标指标“东部工厂订单产值、交付数量和毛利”，数据证据“重点项目订单、报价、交付及验收节点”。
- **业务边界：** 预测不替代产能计划、质量评审或供应链风险评估。

### 互联网公司经营：订阅收入与续费表现

- **角色：** 商业化负责人。
- **问题背景：** 东区业务组希望识别订阅产品、客户分层和市场投放对续费的影响。
- **建议问题：** `本月各业务组订阅收入排名如何？`、`哪个客户分层的订阅收入偏低，需要核查？`、`如果东区业务组市场投入增加10%，价格下调5%，订阅收入会怎样？`。
- **行动示例：** 负责人“赵宁”，目标指标“续费收入、付费席位和大客户扩容”，数据证据“续费客户清单、流失原因和市场转化数据”。
- **业务边界：** 情景结果不是客户续费承诺，需配合客户成功和价格策略验证。

## 关键演示问题索引

每个行业当前提供 17 条与模板意图绑定的问题。进入场景库后可直接点击页面中的问题；以下是跨行业通用的四类提问方式：

| 类别 | 要证明的能力 | 推荐提问 |
| --- | --- | --- |
| 发生了什么 | 事实检索、排行、趋势、贡献 | `本月各区域GMV / 交易额排名如何？` |
| 为什么发生 | 对比线索和核查方向 | `为什么华东GMV / 交易额出现变化？` |
| 接下来怎么办 | 优先级和人工确认行动 | `本月GMV / 交易额最需要优先关注哪个区域？` |
| 预测与模拟 | 趋势预测和假设分析边界 | `下个月GMV / 交易额可能是多少？` |

## 演示时的真实感细节

1. 导入前先说清楚“这是一份模拟业务明细，字段结构和业务逻辑接近真实使用方式，但不包含任何真实个人或客户信息”。
2. 创建行动时使用真实岗位、明确截止日和可核对证据，而不是填写“测试”“明天”等泛化内容。
3. 讲异常时说“优先核查”，讲预测时说“辅助判断”，讲模拟时说“试点假设”。
4. 切换行业前提醒观众：加载场景会替换当前数据并清空查询历史；这是为了保证演示可复现。
5. 配置页只展示流程，不在投屏或录屏环境输入 API Key。
