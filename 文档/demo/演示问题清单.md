# 演示问题清单

## 电商经营主线问题

先在“场景库”加载“电商经营”，再依次复制以下问题到页面顶部输入框或“智能查询”页面：

1. `本月各区域GMV / 交易额排名如何？`
2. `本月商品GMV / 交易额排名如何？`
3. `本月各商品品类GMV / 交易额排名如何？`
4. `最近30天GMV / 交易额趋势如何？`

## 经营决策问题

1. `为什么华东GMV / 交易额出现变化？`
2. `本月GMV / 交易额最需要优先关注哪个区域？`
3. `下个月GMV / 交易额可能是多少？`

## 假设分析问题

`如果华东促销投入增加10%，价格下调5%，GMV / 交易额会怎样？`

## 跨行业备用问题

进入对应行业场景后，不要混用其他行业术语。可直接在场景库的“示例问题”中点击，或者使用以下问题：

| 场景 | 发生了什么 | 为什么发生 | 接下来怎么办 |
| --- | --- | --- | --- |
| 医院运营 | `本月各院区服务收入排名如何？` | `为什么东院区服务收入出现变化？` | `本月服务收入最需要优先关注哪个院区？` |
| 银行经营 | `本月各分行业务收入排名如何？` | `为什么华东分行业务收入出现变化？` | `本月业务收入最需要优先关注哪个分行？` |
| 制造业经营 | `本月各工厂订单产值排名如何？` | `为什么东部工厂订单产值出现变化？` | `本月订单产值最需要优先关注哪个工厂？` |
| 互联网公司经营 | `本月各业务组订阅收入排名如何？` | `为什么东区业务组订阅收入出现变化？` | `本月订阅收入最需要优先关注哪个业务组？` |

## 备用说明

每次查询会显示摘要、只读 SQL、图表和表格。SQL 仅允许单条业务查询，系统不会执行写入、删除或修改操作；没有配置外部 AI 时，系统使用本地规则完成可演示的查询。完整业务背景和建议话术见 [全功能演示素材库](全功能演示素材库.md)。
