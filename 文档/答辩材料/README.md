# 答辩材料包

本目录是可直接用于答辩的材料集合。建议按下面顺序准备：

1. 用 [答辩 PPT 大纲](答辩PPT大纲.md) 制作 10 至 12 页幻灯片。
2. 使用 [答辩陈述稿](答辩陈述稿.md) 练习 7 至 8 分钟主讲。
3. 打开 [现场演示预案](现场演示预案.md)，按顺序完成系统演示并准备离线备选方案。
4. 阅读 [答辩问答库](答辩问答库.md)，熟悉技术、AI、安全、数据与项目管理问题。
5. 需要扩展说明时，查看上级目录的 [答辩主文档](../DEFENSE_GUIDE.md)、[系统设计说明书](../系统设计说明书.md) 和 [测试与验收报告](../测试与验收报告.md)。

答辩前不展示 `.env`、Docker 密码、真实 API Key、个人数据或未经授权的真实业务数据。
