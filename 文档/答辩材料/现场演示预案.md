# 现场演示预案

## 1. 演示前 10 分钟检查

- [ ] 双击根目录 `启动智能BI系统.cmd`，确认浏览器打开 `http://localhost:8080`。
- [ ] 左侧状态显示数据库正常；若配置了 AI，确认不显示真实 Key。
- [ ] 打开 [演示问题清单](../demo/演示问题清单.md) 和 [答辩陈述稿](答辩陈述稿.md)。
- [ ] 浏览一遍场景库，选择电商经营作为主演示场景；医院场景作为切换备选。
- [ ] 关闭与答辩无关的软件、通知和敏感窗口。
- [ ] 确认 Docker Desktop 处于运行状态，但不在现场展示 `.env`、终端历史或密钥。

## 2. 推荐现场顺序（3 分钟）

1. **场景库（20 秒）**：说明五行业一键切换和受控 CSV 模板。
2. **发生了什么（40 秒）**：运行“本月各区域 GMV / 交易额排名如何？”，展示摘要、SQL、图表、结果表。
3. **为什么发生（35 秒）**：运行“为什么本月 GMV / 交易额出现变化？”，说明证据与核查方向。
4. **接下来怎么办（25 秒）**：点击“本月 GMV / 交易额最需要优先关注哪个区域？”，说明建议是待验证行动线索。
5. **报告与预测（45 秒）**：生成月报、展示 Markdown 导出，再打开预测页说明限制。
6. **AI 配置（15 秒）**：只展示模型下拉框和脱敏状态；没有必要现场输入真实 Key。

## 3. 备用方案

| 风险 | 现场处理 |
| --- | --- |
| Docker 未启动 | 等待启动器自动拉起；同时转入 PPT 的架构与截图页。 |
| AI 连接失败 | 说明外部 AI 是可选增强，删除/关闭配置后本地规则模式可完整演示。 |
| 查询结果异常 | 回到场景库重新加载电商场景，再使用模板问题而非自定义问题。 |
| 网络不可用 | 系统的本地规则、MySQL、场景、报告、异常和预测均可离线演示。 |
| 浏览器/投屏异常 | 使用 PPT 的界面截图与答辩材料讲解架构、测试和流程。 |

## 4. 不应在答辩中做的事

- 不临时导入未知格式的真实数据。
- 不展示、复制或读取真实 API Key。
- 不把预测或异常建议描述为确定结论。
- 不执行数据库重置、删除 Docker 卷或修改系统网络配置。
