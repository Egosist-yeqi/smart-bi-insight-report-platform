# 智能 BI 平台功能演示文档

## 演示前准备

1. 在仓库根目录双击 `启动智能BI系统.cmd`。
2. 浏览器自动打开 `http://localhost:8080` 后，确认左下角状态显示数据库正常和本地分析。
3. 演示数据已内置 540 条销售订单，覆盖 5 个区域、6 个产品和 18 个月；不配置 API Key 也能完成整套演示。

如果浏览器提示无法访问，请打开 Docker Desktop，等待底部显示 Engine running 后再次双击启动器。

## 六分钟完整演示

| 顺序 | 页面位置 | 输入或操作 | 预期看到的结果 |
| --- | --- | --- | --- |
| 1 | 左侧“场景库” | 确认“电商经营”为当前场景；需要重新开始时点“加载演示数据” | 加载 540 条电商业务明细、行业术语、模板问题，并产生可追溯的数据批次。 |
| 2 | 左侧“智能查询” | 点击“本月各区域GMV / 交易额排名如何？” | 生成摘要、只读 SQL、柱状图和明细表。 |
| 3 | 顶部输入框 | 输入“本月商品GMV / 交易额排名如何？”并点“运行查询” | 返回商品名称、GMV / 交易额和结果表；可点“导出 CSV”。 |
| 4 | 左侧“仪表盘” | 先查看“指标口径与数据范围”，再在“区域”下拉框选择“华东” | 核对数据截止日期、有效月份和指标公式；GMV、数量、趋势、商品排行同步按华东筛选；点“清空筛选”恢复全局。 |
| 5 | 左侧“异常归因” | 无需输入，等待数据加载 | 看到阈值 18% 的异动列表和区域归因图；可说明这是需要进一步核查的经营线索。 |
| 6 | 左侧“行动中心” | 点击一条“载入草案”，补充负责人和截止日，创建后标记执行中；填写复盘结论后关闭 | 展示建议不等于执行，行动具有负责人、证据、状态和复盘记录。 |
| 7 | 左侧“报告生成” | 选择“月报”，保留“销售概览、区域分析、产品排行、异常指标、趋势预测”，点“生成报告” | 右侧生成报告预览；点“导出 Markdown”下载文件。 |
| 8 | 左侧“趋势预测” | 无需输入，等待数据加载 | 看到历史月度曲线、下一月预测值与“OLS 线性回归”预测依据。 |
| 9 | 左侧“场景库” | 上传 `demo/scenarios/自有数据导入示例_电商.csv`，先点“检查数据质量”，再确认导入 | 预检不写入数据；正式导入后显示自有 CSV 数据源，并在底部生成来源、范围和 SHA-256 指纹。 |

## 行业场景演示

进入左侧“场景库”，可一键切换电商经营、医院运营、银行经营、制造业经营和互联网公司经营。每个场景都会装载 540 条行业演示记录，并把仪表盘、异常和预测页的“金额、数量、项目/产品”等文字替换为行业语义。

建议答辩时先选“医院运营”，展示服务收入、服务人次和医疗服务排行；再切换“制造业经营”，展示订单产值、交付数量和产品线。随后在“智能查询”依次点击“发生了什么、为什么发生、接下来怎么办、预测与模拟”分组的问题，说明系统把事实、核查方向、行动建议和模型假设分开呈现。

需要演示自有数据时，在场景库选择模板后下载 CSV，按 11 列字段填写再上传。先点击“检查数据质量”，确认记录数、日期范围和提醒，再点击“确认导入并替换当前数据”。导入会替换当前数据集，因此建议先使用演示数据完成答辩流程。详细素材见 [行业场景演示素材库](demo/scenarios/README.md)。

## 每个功能怎么用

### 1. 智能查询

入口在左侧“智能查询”，也可以直接使用页面顶部的“输入经营分析问题”输入框。

可直接输入以下任意一句：

- `本月各区域销售额排名如何？`
- `上月华东区销售额最高的产品是什么？`
- `最近30天销售额趋势如何？`
- `哪个产品类别的毛利最高？`
- `本周订单量相比上周下降了吗？`
- `为什么本月华南区销售额出现下降？`
- `下个月销售额可能是多少？`
- `如果华东区促销投入增加10%，价格下降5%，销售额会怎样？`

点击示例问题会立即运行；手动输入后点击“运行查询”。结果区会显示业务摘要、系统生成的只读 SQL、图表和明细表。点击“导出 CSV”可把当前结果交给老师或业务人员查看。查询历史会保留在页面下方。

### 2. 仪表盘

入口在左侧“仪表盘”。顶部有“区域、类别、客户类型”三个下拉筛选框。筛选器下方的“指标口径与数据范围”会展示当前数据集的记录数、起止日期、有效月份、维度覆盖和各指标公式。选择任一条件后，销售额、销售数量、客单价、毛利率、趋势图、区域贡献和产品排行会一起刷新。点“清空筛选”回到全局视图。

建议演示顺序：先展示全局 KPI，再选择“华东”，最后点“清空筛选”，突出多维下钻能力。

### 3. 报告生成

入口在左侧“报告生成”。在“报告配置”中选择“周报、月报或自定义报告”，勾选需要的模块后点“生成报告”。右侧预览生成内容；点“导出 Markdown”得到可继续编辑和提交的报告文件。

推荐答辩操作：选择“月报”，保留全部五个模块，再生成和导出。

### 4. 异常归因

入口在左侧“异常归因”。本页不需要输入，系统自动以完成月度数据计算异常，并以 18% 阈值呈现提醒。左侧表格用于找出变化显著的区域，右侧图表用于比较区域贡献。

说明口径：异常是经营预警，不等同于自动判定根因；页面提示会引导继续核查产品组合、客户订单和出货节奏。

### 5. 趋势预测

入口在左侧“趋势预测”。页面自动展示历史销售额与下一月预测。预测采用 OLS 线性回归，仅用于辅助分析，不代表业务承诺。

### 6. 行动中心

入口在左侧“行动中心”。右侧“建议草案”会随当前行业场景展示三条可用的核查方向，点击“载入草案”后，补充负责人、截止日期、目标指标和数据证据，再点击“创建待确认行动”。

创建后可点击“标记为执行中”。结束时必须在同一行动项中填写“复盘结论”，再点击“完成并复盘”；若没有结论，系统会阻止关闭。这个顺序用于展示系统把数据建议、人工决策和实际结果明确区分。

### 7. 系统配置和自有 AI API

入口在左侧“系统配置”。不填写任何内容时，系统保持“本地分析”模式，适合稳定演示。

“AI 服务类型”默认选中 **DeepSeek API**。此模式已自动填入官方地址、默认模型和安全网络策略，用户只需填写自己的 API 密钥，点击“连接测试”，成功后再点“保存配置”。

若要使用其他服务，在下拉框选择“其他 OpenAI 兼容服务”，再填写：

| 字段 | 输入内容 |
| --- | --- |
| 服务名称 | 例如 `我的兼容模型服务` |
| Base URL | 例如 `https://你的服务地址/v1` |
| 模型 | 服务商提供的模型 ID，例如 `gpt-4o-mini` |
| 超时秒数 | 建议 `30` |
| API 密钥 | 首次保存必须填写自己的 Bearer Key |

保持“启用该 AI 服务”勾选，先点“连接测试”，成功后再点“保存配置”。API Key 保存后只显示脱敏提示；更换 Base URL 时必须重新输入 Key。除非服务是可信的内网服务，否则不要勾选“允许访问私有网络地址”。点“删除配置”即可回到本地分析模式。

## 演示结束检查

1. 智能查询至少展示一次图表和 CSV 导出。
2. 仪表盘至少展示一次筛选前后对比。
3. 报告至少生成一次并导出 Markdown。
4. 强调默认本地分析可用，外部 AI API 为用户自愿启用。
5. 在行动中心至少创建一条行动并填写复盘，展示“发现、执行、复盘”的完整闭环。
6. 至少说明一次正式导入的数据版本追溯，强调原始 CSV 不会作为批次历史保存。

更多可直接朗读的内容、问题卡片和检查清单见 [演示素材包](demo/README.md)；需要覆盖所有功能时直接使用 [全功能演示素材库](demo/全功能演示素材库.md)。
