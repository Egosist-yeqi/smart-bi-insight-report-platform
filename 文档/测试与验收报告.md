```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1
```

轻量前端验证可执行：

```powershell
npm.cmd test
npm.cmd run build
```

## 5. 已知边界

- 本系统是本地可演示原型，不提供登录、企业 RBAC、多租户与生产级监控告警。
- 预测基于历史趋势，仅作辅助判断；异常归因提供核查线索，不应当作因果证明。
- 外部 AI 的质量、可用性和费用由用户配置的服务决定；AI 不可用时系统自动降级为本地规则模式。
- 自有数据必须先映射到 11 个标准字段，系统不对未知字段擅自生成 SQL。
