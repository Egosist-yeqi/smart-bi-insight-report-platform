## 推荐阅读路径

1. 初次了解项目：阅读根目录 [README](../README.md)、[需求文档](PRD.md) 和 [系统设计说明书](系统设计说明书.md)。
2. 需要运行系统：阅读 [部署与运维手册](部署与运维手册.md)，然后双击根目录 `启动智能BI系统.cmd`。
3. 准备演示或答辩：从 [答辩材料](答辩材料/README.md) 开始，并配合 [演示问题清单](demo/演示问题清单.md)。
4. 让 AI 协作开发：阅读根目录 [AI_PROJECT_CONTEXT.md](../AI_PROJECT_CONTEXT.md)。

## 资料维护约定

- 新的项目文档、演示素材和答辩材料统一放在本目录，不再新建 `docs` 目录。
- 不提交 `.env`、数据库导出、真实 API Key、真实业务数据或含密钥的截图。
- 代码、接口或场景发生实质变化时，同步更新本目录中的设计、测试和演示文档。
