# 数据版本追溯说明

## 1. 目的

当用户切换行业场景或导入自己的 CSV 后，仪表盘、查询、报告和预测都基于新的数据集计算。数据版本追溯用于回答“当前结果来自哪一批数据”，避免在演示或复盘时混淆不同来源的数据。

## 2. 自动记录的内容

每次点击“加载演示数据”或“确认导入并替换当前数据”后，系统在 `data_import_batch` 中新增一条记录：

- 来源类型：演示数据或自有 CSV。
- 行业模板、记录数、数据起止日期和创建时间。
- 由业务记录编号、日期、金额和收益生成的 SHA-256 数据指纹。

CSV 原文不会额外保存到该表，API Key、文件路径和原始文件名也不进入批次记录。

## 3. 使用方法

打开“场景库”，在底部“数据版本追溯”查看最近 8 个批次。每条记录展示来源、覆盖范围和完整指纹。导入前的“检查数据质量”是只读操作，不会生成批次、不替换数据，也不会清空查询历史。

## 4. 当前边界

- 当前记录用于本地原型中的来源辨识，不提供原始 CSV 的下载、版本回滚或用户级权限控制。
- 指纹用于判断数据内容是否相同，不能代替企业级数据治理、签名、备份和审批流程。
- 批次历史会在场景切换后保留；查询历史和当前明细数据仍按原有规则被替换。
