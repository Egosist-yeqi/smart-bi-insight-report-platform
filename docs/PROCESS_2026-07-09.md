# 2026-07-09 开发过程文档

根据 `docs/PRD.md` 开始实现「智能 BI 数据洞察与报告生成平台」，优先完成一个可运行、可演示的 MVP 原型，并记录本次工作达到的目标。

## 本次完成内容

### 1. 前端工程初始化

已创建 React + Vite 前端工程结构：

- `package.json`
- `index.html`
- `vite.config.js`
- `src/main.jsx`
- `src/App.jsx`
- `src/styles.css`

当前应用为单页 BI 工作台，包含左侧导航、顶部自然语言查询栏和多业务页面。

### 2. 样例业务数据

已在 `src/data/sampleData.js` 中准备演示数据，覆盖：

- 订单日期和月份。
- 区域、省份。
- 产品、产品类别。
- 客户类型。
- 销售数量、销售额、毛利。

演示数据用于支撑自然语言查询、图表展示、异常分析、预测和报告生成。

### 3. 自然语言查询与 Text-to-SQL 演示

已在 `src/lib/queryEngine.js` 中实现基于规则的自然语言查询原型。当前支持典型问题：

- 上月华东区销售额最高的产品是什么？
- 本月各区域销售额排名如何？
- 最近 30 天销售额趋势如何？
- 哪个产品类别的毛利最高？
- 本周订单量相比上周下降了吗？
- 为什么本月华南区销售额出现下降？
- 下个月销售额可能是多少？
- 如果华东区促销投入增加 10%，价格下降 5%，销售额会怎样？

查询结果会返回：

- 识别意图。
- 生成 SQL。
- SQL 安全校验结果。
- 结构化结果行。
- 查询解释和自然语言摘要。
- 推荐图表类型。

### 4. 指标、图表和仪表盘

已在 `src/lib/analytics.js` 中实现基础分析能力：

- KPI 汇总。
- 环比变化。
- 区域排名。
- 产品排行。
- 类别毛利排行。
- 周/月趋势。
- 异常检测。
- 趋势预测。
- 假设分析。

界面已包含：

- KPI 指标卡。
- 条形图。
- 折线图。
- 结果表。
- 多维筛选器。
- 产品贡献列表。

### 5. 自动报告生成

已在 `src/lib/reporting.js` 中实现报告生成逻辑，支持按模块组合：

- 销售概览。
- 区域分析。
- 产品排行。
- 异常指标。
- 趋势预测。

报告页支持：

- 周报、月报、自定义报告类型选择。
- 模块勾选。
- 报告预览。
- Markdown 导出。

### 6. 异常归因与预测演示

已实现演示版异常和预测能力：

- 异常页展示区域销售额波动和归因说明。
- 趋势页展示历史销售趋势和下月预测。
- 假设分析说明促销投入、价格下降对销售额的估算影响。

当前归因和预测为演示算法，后续接入更多业务字段后可替换为真实模型。
