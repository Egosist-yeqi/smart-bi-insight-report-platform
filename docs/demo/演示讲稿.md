# 六分钟演示讲稿

## 0:00 - 0:30 开场

“这是智能 BI 数据洞察与报告生成平台。它把自然语言查询、仪表盘分析、自动报告、异常归因和趋势预测放在同一个工作台里。系统使用 MySQL 保存业务数据，默认本地分析模式不需要配置任何第三方 API。”

## 0:30 - 1:40 智能查询

“我先在顶部输入 `本月各区域销售额排名如何？` 并运行。系统返回业务摘要、只读 SQL、柱状图和明细结果。这样业务人员不需要手写 SQL，也能获得可核对的数据结果。”

“再输入 `上月华东区销售额最高的产品是什么？`。我可以直接导出 CSV，方便继续处理或附在汇报材料中。”

## 1:40 - 2:40 仪表盘与筛选

“进入仪表盘可以看到全局销售额、销售数量、客单价和毛利率。这里我把区域切换为华东，所有 KPI、趋势和产品排行会同步刷新；清空筛选后恢复全局视图。”

## 2:40 - 3:40 自动报告

“进入报告生成，选择月报并保留销售概览、区域分析、产品排行、异常指标和趋势预测。点击生成报告后，右侧会给出预览，并能导出 Markdown，后续可继续编辑。”

## 3:40 - 4:40 异常和预测

“异常归因页面会依据完成月度数据识别显著变化，并按区域展示贡献。它提供预警线索，而不是替代业务判断。趋势预测页面使用历史月度销售额计算下月预测，明确提示预测仅供参考。”

## 4:40 - 5:30 自有 AI API

“系统默认本地模式就能完整演示。如果用户需要自己的模型服务，可以在系统配置填写 OpenAI 兼容的 Base URL、模型和 API Key，先连接测试再保存。密钥保存后只显示脱敏状态，也可以随时删除并回到本地模式。”

## 5:30 - 6:00 收尾

“系统通过 Docker Desktop 一键启动，前端、FastAPI 后端和 MySQL 一起运行；演示数据已预置，打开即可测试。项目仓库同时提供操作文档、演示问题和启动器，其他人也可以快速上手。”
