# 演示问题清单

## 建议主问题

依次复制以下问题到页面顶部输入框或“智能查询”页面：

1. `本月各区域销售额排名如何？`
2. `上月华东区销售额最高的产品是什么？`
3. `哪个产品类别的毛利最高？`
4. `最近30天销售额趋势如何？`

## 强调智能分析能力的问题

1. `本周订单量相比上周下降了吗？`
2. `为什么本月华南区销售额出现下降？`
3. `下个月销售额可能是多少？`

## 假设分析问题

`如果华东区促销投入增加10%，价格下降5%，销售额会怎样？`

## 备用说明

每次查询会显示摘要、只读 SQL、图表和表格。SQL 仅允许单条业务查询，系统不会执行写入、删除或修改操作；没有配置外部 AI 时，系统使用本地规则完成可演示的查询。
