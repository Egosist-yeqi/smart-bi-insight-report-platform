## 项目名称

智能 BI 数据洞察与报告生成平台

## 项目定位

本项目面向企业经营分析和数据决策场景，构建支持自然语言查询、自动报告生成、异常归因、趋势预测和可视化分析的智能 BI 平台。

## 主要功能

1. 自然语言数据查询
   - 智能解析用户日常语言提问，例如“上月华东区销售额最高的产品是什么？”
   - 自动转换为 SQL 查询。
   - 以图表和文字形式展示查询结果。
   - 支持多维度下钻分析。

2. 自动报告生成
   - 根据预设模板和数据，自动生成包含核心洞察、图表和结论的周期性分析报告。
   - 支持周报、月报。
   - 支持用户自定义报告结构和内容，满足不同场景需求。

3. 异常检测与归因分析
   - 自动监测关键业务指标异动，及时发现异常波动。
   - 通过多维度下钻分析，用自然语言解释异动的可能原因和影响范围。

4. 预测与模拟
   - 基于历史数据进行销量、收入等指标的趋势预测。
   - 允许用户通过“假设分析”提问进行业务模拟，评估不同策略的影响。

5. 数据可视化与交互
   - 提供直观的数据可视化界面。
   - 支持图表联动、筛选和导出。

## 项目特色

以 Text-to-SQL 和自然语言数据分析为核心，强调业务指标理解、多维下钻、自动洞察生成和可视化报告输出，适合训练数据应用与大模型结合能力。

## 技术架构

- AI 核心：Python、Text-to-SQL、大模型（数据分析与报告生成）、Agent 技术
- 后端服务：PyTorch、Nginx
- 前端：Vue.js
- 数据：MySQL 8.0
